# macOS Standard Keyboard Shortcuts

> Sources: Apple HIG [keyboards](../hig/keyboards.md), *Tahoe Course Companion*, and Tahoe release notes.  
> On Linux, the ⌘ (Command) key maps to **Super** (Windows key).

---

## System Shortcuts
| Shortcut | Action |
|---|---|
| `⌘Space` | Spotlight Search |
| `⌘1` / `⌘2` / `⌘3` / `⌘4` (in Spotlight) | Switch modes: All / Files / Apps / Clipboard |
| `↑` (in empty Spotlight) | Search query history |
| `⌘Tab` / `⇧⌘Tab` | App Switcher (`Q` quits focused app, `H` hides app) |
| `⌘\`` / `⇧⌘\`` | Cycle forward/backward through windows of active application |
| `⌃↑` | Mission Control · `⌃↓` App Exposé · `⌃←`/`→` Switch workspaces |
| `⌘H` / `⌥⌘H` | Hide Application / Hide Other Applications |
| `⌘M` / `⌥⌘M` | Minimize Window / Minimize All Windows of active app |
| `⌘W` / `⌘Q` | Close Window / Quit Application |
| `⌃⌘F` | Toggle Fullscreen |
| `⌃⌥F` | Maximize / Fill Screen |
| `⌥⌘Esc` | Force Quit Applications dialog |
| `⌥⌘D` | Toggle Dock visibility (Auto-hide) |
| `⌘,` | Open Application Preferences / Settings |
| `⇧⌘3` / `⇧⌘4` / `⇧⌘5` | Capture Screen / Region / Capture Toolbar & Screen Recording (add `⌃` to copy to clipboard; `Space` toggles window selection) |
| `⌃⌘Space` | Character Viewer (Emoji & Symbols) |
| `⌃⌘Q` | Lock Screen |
| `⌘?` | Help / Menu Search |

## Editing Shortcuts
* `⌘Z`: Undo · `⇧⌘Z`: Redo
* `⌘X`: Cut · `⌘C`: Copy · `⌘V`: Paste · `⌥⇧⌘V`: Paste and Match Style
* `⌘A`: Select All · `⌘F`: Find · `⌘G`: Find Next
* `⌘B`: Bold · `⌘I`: Italic · `⌘U`: Underline
* `⌘N`: New · `⌘O`: Open · `⌘S`: Save · `⌘P`: Print · `⌘T`: New Tab

---

## Modifier Glyphs & Ordering
`⌘` Command · `⌥` Option / Alt · `⌃` Control · `⇧` Shift · `⇪` Caps Lock · `⎋` Escape · `⌫` Delete · `↩` Return · `⇥` Tab · `🌐` Fn / Globe.  
In menu dropdowns, modifiers appear strictly in the sequence **⌃ ⌥ ⇧ ⌘** before the key character (Medium 13 pt, subdued gray).
